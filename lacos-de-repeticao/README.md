# Exercícios - Laços de repetição

Exercícios em Java que utilizam `for`, `while`, `do-while` e `if`,`elsif`,`else`
quando necessário.

## Exercícios

- **n7:** Lê o código da matrícula e as 3 notas do aluno, calculando a média
  de cada aluno e repetindo para cada aluno até o usuário digitar uma matrícula cujo código é zero. (aluno inválido/não existente)
